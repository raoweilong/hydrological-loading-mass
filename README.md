# Global Hydrological Loading Model (GHLM) for the Tibetan Plateau

This repository provides a global-scale **Hydrological Loading Mass Field (GHLM)** model developed using multi-source satellite observations and global hydrological models. The GHLM model finely simulates the long-term trends of terrestrial water storage (TWS) over the **Tibetan Plateau**, enabling accurate estimation of long-term hydrological loading deformation in the region.

Citation
If you use this model in your research, please cite:

Rao, W. L., Liu, J. T., Feng, T. F., et al. (2025). What is the present-day tectonic uplift rate of the Tibetan Plateau?. Earth and Planetary Science Letters, 662, 119389.
